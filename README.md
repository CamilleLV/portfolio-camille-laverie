# 🍃 Camille Laverie - Data Engineer Portfolio

Welcome to the repository of my personal portfolio! This project showcases my skills, professional experiences, academic background, and technical blog posts. 

You can view the live version here: [camillelv.github.io](https://camillelv.github.io)

## ✨ Features

- **Bilingual Interface:** Seamless toggle between French (FR) and English (EN) for international recruiters.
- **Dynamic Content:** Projects, skills, and experiences are generated dynamically from a centralized JSON file.
- **Integrated Blog:** A built-in article reader supporting rich text, code snippets, and dynamic routing.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing with modern UI/UX practices.
- **Direct CV Download:** One-click download for both French and English resumes.

## 🛠️ Tech Stack

- **Framework:** React.js
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Deployment:** GitHub Pages

## 🚀 Local Development

To run this project locally on your machine, follow these steps:

1. Clone the repository:
   `git clone https://github.com/CamilleLV/camillelv.github.io.git`

2. Navigate to the project directory:
   `cd camillelv.github.io`

3. Install dependencies:
   `npm install`

4. Start the development server:
   `npm run dev`

The application will open in your default browser at `http://localhost:5173` (or similar).

## 📂 Project Structure

- `src/App.jsx`: Main React component containing the layout and logic.
- `src/portfolioData.json`: Centralized data file (FR/EN) containing profile info, skills, and experience.
- `public/`: Contains static assets like images and downloadable PDF resumes.
